WORKFLOW

세 단계로 쇼케이스를 만듭니다.

01

화면을 장면으로 추가

PNG·JPG·WebP를 여러 장 올리거나 브라우저의 화면 공유 기능으로 탭·창의 현재 프레임을 캡처합니다.

02

카메라와 커서 연출

장면마다 줌과 포커스 지점을 정하고 커서가 대상 위치로 이동해 클릭하는 흐름을 미리봅니다.

03

WebM으로 렌더링

Canvas와 MediaRecorder를 사용해 모든 장면을 순서대로 재생하고 WebM 파일로 기기에 저장합니다.

GITHUB PAGES SCOPE

정적 웹앱에서 가능한 범위를 명확히 했습니다.

가능: 이미지 업로드, 사용자 승인 기반 화면 캡처, 장면 편집, 줌·팬·커서 연출, 로컬 프로젝트 저장, WebM 렌더링.

불가능: URL만 입력해 다른 사이트를 몰래 열고 자동 클릭하거나 임의 사이트 DOM을 직접 조작하는 기능. 브라우저의 동일 출처 정책과 화면 캡처 권한 때문에 GitHub Pages만으로는 할 수 없습니다.

나중에 “URL 입력 → 자동 브라우징 → 완성 영상”까지 확장할 때만 Playwright/Chromium 렌더링 워커 같은 별도 백엔드를 붙이면 됩니다.
