공개 웹사이트는 외부 브라우저 캡처 API를 통해 가져옵니다. 한 번의 전체 페이지 캡처를 여러 장면으로 분해해 움직임을 만들 수 있어 무료 요청량을 아낍니다.

HOW IT WORKS

정적 사이트이지만, 제작 흐름은 실제로 동작합니다.

01

URL 캡처

공개 URL을 서버 측 브라우저로 렌더링해 이미지로 가져옵니다. 전체 페이지 캡처는 한 장의 긴 이미지를 여러 카메라 장면으로 재사용합니다.

02

템플릿 편집

기본 템플릿을 적용한 뒤 줌·포커스·커서·전환을 수정하고, 현재 결과를 내 템플릿으로 로컬 저장하거나 JSON으로 백업할 수 있습니다.

03

오디오 포함 렌더링

내장 생성형 사운드 또는 업로드한 오디오를 Canvas 영상 스트림과 결합해 브라우저에서 WebM으로 기록합니다.
