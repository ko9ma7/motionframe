    URL 분석 세부 설정

    Concept Director가 기본값을 채웁니다. 필요한 경우에만 캡처 방식, 뷰포트, 분석 범위를 여기서 세부 조정하세요.

    분석 범위 · 먼저 여기까지만 정합니다

    여러 URL을 입력하면 그 순서 자체를 스토리 순서로 사용합니다. 같은 문서의 hash URL은 동일 페이지를 반복 분석하지 않고, 해당 위치에서 보여줄 챕터로 취급합니다.

    URL은 한 줄에 하나씩 입력하며 입력 순서가 영상의 챕터 순서가 됩니다. Ctrl/⌘ + Enter로 바로 쇼릴을 만들 수 있습니다. Microlink 브라우저에서 제목·헤딩·메뉴·버튼·링크의 실제 화면 좌표와 href를 함께 읽습니다. 다음 페이지와 연결되는 링크가 있으면 커서 이동 → 클릭 → 다음 페이지 진입까지 기본 연출안에 자동 연결합니다.

    HOW IT WORKS

    정적 사이트이지만, 제작 흐름은 실제로 동작합니다.

    01

    DOM + 링크 분석

    공개 URL을 서버 측 브라우저로 렌더링하고 제목·섹션·메뉴·CTA의 실제 좌표와 href를 읽어 페이지별 Blueprint를 만듭니다.

    02

    Auto Director

    사용자가 정한 분석 범위 안에서 실제 위치 순서와 링크 목적지를 기준으로 Flow를 만들고, 체크만 바꾸면 장면 순서를 다시 계산합니다.

    03

    모션 + 오디오 렌더링

    자동 연출안을 모션 템플릿과 직접 그린 경로로 다듬고, 내장 사운드 또는 업로드 음원을 영상과 함께 WebM으로 기록합니다.
